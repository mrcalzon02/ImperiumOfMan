# Custom mercenary classes

Design draft for Quasimorph **1.0.4.590s.969afc6**. The **Necromancer** binds defeated enemies into temporary Chaos Undivided servants. The **Combat Engineer** repairs, retrieves, and redeploys machines. The **Vigils** hold warded ground and fight the Bramfatura creatures that get through. Unlock gates and numeric values below are starting points for playtesting.

| Perk status | Implementation scope |
| --- | --- |
| **Reuse** | Reference the vanilla perk ID and its existing ranks, triggers, and values. |
| **Extend** | Reuse an existing game action or effect. Add the targeting, conditions, or class interaction described in the row. |
| **New** | Add a distinct behavior or persistent state. Reuse native targeting, item, combat, and save systems where they fit. |

## Class progression and perk swapping

| Class | Proposed class chip route |
| --- | --- |
| Necromancer | A one-time class chip from the first eligible successful **Chaos Undivided–sponsored** contract at **+25 standing** and **Chaos Tech 3**. Check eligibility at completion, including reputation earned on the contract. +25 matches the standing required for *The Starless March*. |
| Combat Engineer | A one-time Imperial class chip for successful **Havoc Control** in support of the Imperium, at **Imperial Tech 5**. |
| Vigils | A one-time Imperial class chip for successful **Titan Vault Containment** in support of the Imperium, at **Imperial Tech 10**. |

All three chips use the native class unlock. A lost chip can be earned again on the next eligible contract. Suppress duplicate rewards while the crew owns the chip or has learned the class. Apply the faction gates to reward acquisition. Learned classes follow native unlock persistence when faction standing changes. Exclude these three records from the random starting-class roll and the generic class-chip pool so mission rewards remain the ordinary unlock route. [Faction campaign standing](src/Plugin.FactionCampaigns.cs) · [Imperial contract tiers](IMPERIAL_FORMATIONS_DESIGN.md)

The six slots are defaults for each class. The Magnum can borrow perks from unlocked classes. Active actions follow the equipped perk, and passive upgrades check for the relevant servant, deployed machine, or ward. A borrowed upgrade alone leaves the relevant action unavailable. Explain prerequisites in the perk tooltip and surface unavailable reasons on the action when applicable. Custom perks use the native Basic, Advanced, Master, and Legend ranks. The tables identify the progression lever for each perk. Tune XP thresholds after the baseline actions work.

The class action buttons appear below ship support during raids. A Necromancer with an empty pact slot can select **Attune Raise the Fallen**, then cast from the usual pact control. **Greater Vessel** toggles the optional Bound Ash cost for the next cast and remains selected until toggled again. The Engineer's doorway action displays the package selected from inventory. The Vigils button shows remaining ward turns and seals after placement.

## Necromancer

Flauros already converts nearby corpses into allied zombies. Fury Sigil and Soulforge Muster already summon Undivided creatures onto free tiles. The Necromancer uses **one chosen enemy corpse** to bind a temporary daemon, then decides whether to keep it fighting, sacrifice it, or invest resources in a stronger vessel. [Undivided pacts and curse](CHAOS_UNDIVIDED_DESIGN.md#skull-pacts-and-rituals) · [Undivided summoning implementation](src/Plugin.ChaosPacts.cs)

| Slot | Perk | Status | Effect and progression |
| --- | --- | --- | --- |
| 1 | **Raise the Fallen** | **Extend** | Unlock the corpse-targeted Undivided pact when equipped. Select one eligible hostile corpse within two tiles and raise a Fury for eight player turns. It follows the clone. Start with one active bound servant. Reuse corpse selection, allied spawning, and the pact's charge and curse. Gain XP on a successful binding. Ranks improve targeting range up to three tiles. |
| 2 | **Grave Binding** | **Extend** | Extend the lifetime of a daemon created by Raise the Fallen. Reuse timed summon expiration. Start at two extra turns and scale to five. Gain XP the first time each newly bound servant wounds a hostile creature. The servant cap stays at one. |
| 3 | **Sacrificial Release** | **New** | Spend an action to order the bound servant to strike one adjacent hostile target and expire. Use the servant's native attack with a rank-scaled damage bonus. Check eligibility before committing the action. Gain XP when the strike resolves. The servant expires even if the attack misses. |
| 4 | **Greater Vessel** | **Extend** | When raising a servant, spend one **Bound Ash** to bind a hardier Fury using the same model and attacks. Ranks increase the health bonus. The improved servant occupies the same slot and uses the same duration and reward rules. Gain XP on a successful enhanced binding. |
| 5 | **Possession** | **Reuse** | Use `possession_basic` and its native upgrades. It reduces pact recharge requirements and curse penalties. Native pact use governs XP. |
| 6 | **Ritualism** | **Reuse** | Use `ritualism_basic` and its native upgrades. Using eligible ritual items temporarily accelerates perk cooldown recovery. Keep the native activation, cooldown, and XP rules. |

**Pact slot.** Raise the Fallen uses the existing pact slot and the Undivided curse. Selecting it takes the slot normally occupied by Fury Sigil, Soulforge Muster, or another pact. Its class perk grants access to the pact and stays required to equip it. On a class change or perk swap, clear the selection if Raise the Fallen is no longer equipped, following the native pact removal rules. Confirm this works through the native loadout before adding any new pact controls. A successful raise consumes the pact charge and applies the curse once. An invalid corpse, blocked spawn tile, or occupied servant slot leaves the charge and materials available. Keep the native recharge and curse costs above zero with the strongest eligible perk combination.

**Corpses and servant lifetime.** Start with ordinary hostile human corpses. A corpse that has been looted remains eligible if its body is usable. Exclude allies, machines, summons, and protected objective bodies. If a tile holds several bodies, identify which one is being offered before confirmation. On success, move any remaining loot to the floor once, consume that corpse, and record the servant. The same body cannot also fuel Flauros, a revive item, or another raise. Natural expiry, death, sacrifice, and leaving the floor end the bond. The servant's death generates no loot, bounty, corpse, or Quasimorphosis reward. The activation cost, remaining lifetime, and active-servant limit persist through save and load. [Chaos bounty rules](src/Plugin.ChaosEnemies.cs) · [Existing pact records](src/Plugin.ChaosPacts.cs)

## Combat Engineer

Stationary Defense already gives stronger turrets and longer placement range. The native Engineering Repair Kit treats compatible mechanical wounds, and the Reanimatron already revives a dead cyborg as an ally. The Engineer takes a machine through a full raid cycle. Service it in place, move it through a doorway, or trade the immediate help it provides for the chance to carry it out. [Imperial automata components](src/Plugin.AutomataSupply.cs) · [Existing robot and turret variants](src/Plugin.DeployableWorkshops.cs)

| Slot | Perk | Status | Effect and progression |
| --- | --- | --- | --- |
| 1 | **Field Service** | **Extend** | Use an existing compatible mechanical treatment on an adjacent damaged friendly machine. Reuse native wound and repair validation. Scale the recovery on a successful treatment while keeping the normal charge cost. Gain XP only when a valid machine benefits. The Reanimatron remains the item for an immediate reboot. |
| 2 | **Recover Chassis** | **New** | Pack up an adjacent friendly machine as a recoverable chassis and store its supported damage state. Start with the industrial robot. Packing costs two action points initially and one at higher rank. Gain XP on the first successful pack of a given unit during a raid. Redeploy from the native item placement flow. |
| 3 | **Doorway Deployment** | **Extend** | Target an adjacent closed, unlocked door while using an eligible robot package. The clone opens the door normally and sends the robot to the first valid tile beyond it while staying outside. Use the native door and placement actions, including their noise and action costs. Gain XP on successful placement through the doorway. Ranks shorten the robot's post-placement activation delay where the record has a delay to reduce. |
| 4 | **Wreck Reclamation** | **New** | Recover a dead eligible machine as a damaged chassis. Start with friendly wrecks. Higher ranks unlock eligible hostile industrial machines, then supported security robots, drones, and turrets after each type passes the recovery tests. The kit consumes an existing spare component and returns a chassis that requires refurbishment aboard the Magnum. Gain XP once per reclaimed wreck. |
| 5 | **Stationary Defense** | **Reuse** | Use `stationary_defense_basic` and its native upgrades. Keep vanilla placement range and the health and damage bonuses for units the native record marks as eligible. |
| 6 | **Gear Maintenance** | **Reuse** | Use `gear_maintenance_basic` and its native upgrades. Keep vanilla physical protection and armor durability. These protect the clone while working on a machine. |

**Machine condition and eligibility.** Start by preserving the industrial robot's identity, current health, supported mechanical damage, and carried equipment or cargo where applicable. Redeployment uses the same chassis condition and the native loading state. Apply spawn and turret bonuses only where the normal record permits them. Repacking and redeploying must never refill health or ammunition or create a second inventory. Treat each machine, package, or wreck as one unit throughout the transition. Extraction transfers the package through the normal cargo path. If a machine type cannot round-trip its state, keep it out of recovery until it can. Select eligible machine IDs explicitly. This keeps implanted humans, mission units, and Undivided daemon engines outside the recovery pool even where their body donors are mechanical. [Native donors and Imperial variants](src/Plugin.DeployableWorkshops.cs) · [Undivided body donors](src/Plugin.ChaosEnemies.cs)

**Door and wreck outcomes.** Doorway Deployment uses an ordinary door, a visible legal destination after it opens, and an eligible mobile robot package. A blocked, occupied, or newly invalid destination leaves the package in hand. If the door was already opened by the action, preserve the opening and its cost. Locked doors, scripted doors, and invisible destinations retain their native restrictions. A usable wreck can be rebooted with a Reanimatron or reclaimed. Stripping its essential parts removes the reclamation option. Use the native corpse eligibility and inventory rules where applicable, and preserve any loose loot already obtained. Consume the wreck exactly once when reclamation succeeds. Compare the resulting chassis, materials, and labor with the existing automata economy before expanding the supported roster.

## Vigils

The existing Aegis Ward reduces the current Quasimorphosis meter and helps treat Chaos wounds. The Vigils establish a temporary ward that slows **future ambient buildup** and can suppress **eccolapse**, the emergence of a Quasimorph from a living or dead host. The ward gives the clone time to hold an objective or take a fight. Moving on gives up its local advantage. [Aegis Ward](src/Plugin.GreyKnights.cs) · [Titan Vault Containment](IMPERIAL_FORMATIONS_DESIGN.md)

| Slot | Perk | Status | Effect and progression |
| --- | --- | --- | --- |
| 1 | **Vigil Ward** | **New** | Place one ward on a visible legal tile. While the clone is within two tiles, shave one point from each positive ambient Quasimorphosis tick, down to zero. Start with eight player turns and one placement per floor. Rank progression extends duration. Gain XP on the first ambient tick reduced by each placement. |
| 2 | **Seal the Breach** | **New** | While the clone holds the ward, suppress an ordinary eccolapse whose host or corpse is within it. Start with one suppression charge per placement and scale to three. Spend a charge and award XP only when an emergence would otherwise occur. A living host remains eligible for later attempts after protection ends. |
| 3 | **Banishment** | **New** | While holding the ward, the clone's first direct wound on an eligible hostile inside the ward marks it for two turns. The next direct hit by that clone while both remain under the ward gains a rank-scaled damage bonus of its normal type, then consumes the mark. Each target can be marked once per ward. Gain XP when a follow-up hit consumes the mark. |
| 4 | **Shielding** | **Reuse** | Use `shielding_basic` and its native upgrades. Keep its elemental-resistance coverage and XP trigger. |
| 5 | **Knife Fight** | **Reuse** | Use `cold_weapon_wielding_basic` and its native upgrades. Keep weapon eligibility and strike accuracy, including support for blade-class Imperial weapons. |
| 6 | **First Aid** | **Reuse** | Use `first_aid_basic` and its native upgrades. Keep the native wound-treatment chance and XP trigger. |

**Ward scope.** The game tracks Quasimorphosis for the raid. Being inside the ward controls when the ambient modifier applies to that raid-wide meter. Preserve the meter's existing floors, negative changes, and explicit changes from items, kills, and scripts. Suppression checks the location of the host or corpse in both ordinary game-driven emergence paths. Scripted spawns, forced phase transformations, mutations, Baron transitions, and required mission targets retain their own rules. An active ward ends on expiration or floor exit. Spending the last suppression charge leaves its ambient effect active through the remaining duration. Re-entering the area restores its effects for the remaining duration and charges. The HUD shows the radius, time, and charges.

**Combat targets.** Banishment applies to hostile native Bramfatura creatures and explicitly tagged Undivided daemons, including eligible daemon engines. A hostile already on the map stays in play when a ward is placed. Preserve existing boss immunities and scripted phases. The follow-up consumes the mark once and cannot mark the target again through its own damage. Shielding, Knife Fight, and First Aid remain useful in raids with little or no ambient Quasimorphosis.

## Prototype order and acceptance checks

1. **Class records and acquisition.** Verify one class chip for each documented route, including an existing campaign and a new campaign with randomized starters. Test the Chaos reward just below and at both gates, on a failed contract, and when the crew already holds or has learned the chip. Open the class editor and verify all six slots and the reused progression chains.
2. **Necromancer.** Prototype Raise the Fallen with one Fury before adding its three supporting perks. Test a looted body, a stacked corpse tile, a blocked spawn, and a Flauros or revival interaction targeting the same body. Save and reload before and after the raise. Check pact charge, curse, loot, duration, and cap. Attempt a second raise, then test death, expiration, sacrifice, and a floor change. Confirm a servant death leaves the Quasimorphosis meter and reward totals alone.
3. **Combat Engineer.** Pack, extract, refurbish if needed, and redeploy one damaged industrial robot. Compare its state before and after every transition, with save/load while deployed and while packed. Test ordinary, occupied, locked, and scripted doors. Add wreck recovery after the live loop works, then try both reclamation and native reboot on the same wreck in each order. Compare recoverable value with the cost of replacing the unit.
4. **Vigils.** Compare the same seeded raid with and without the ward. Observe positive and negative ambient ticks, entry and exit, living-host and on-death emergence, a spent seal, and floor transfer. Test an ordinary Quasimorph, an Undivided daemon engine, and a scripted Baron arrival. Save and reload with an active ward and a marked enemy. Track whether the ward buys time to finish an objective while preserving the encounter.
5. **Mixed classes.** Move each signature perk through the Magnum editor and run it on a vanilla class. Try an upgrade with its prerequisite absent. Pair Raise the Fallen with high-rank Possession and Ritualism, Doorway Deployment with Stationary Defense, and Vigil Ward with the Aegis Ward. Check that native effects still apply once and that the combined build preserves costs, caps, and useful XP.
